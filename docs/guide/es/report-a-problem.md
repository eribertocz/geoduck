# Reportar un problema

<span class="gd-time">2 minutos</span>

1. **? › Reportar un problema…** copia el diagnóstico del entorno (versiones de QGIS, Python y el motor; nunca
   tus datos).
2. Escribe qué hacías, qué esperabas y qué pasó. Si hay un error, cópialo con el icono de copiar de su tarjeta.
3. Pega todo en el reporte, junto con el diagnóstico.

Un ejemplo pequeño que lo reproduzca (unas filas en SQL) ayuda mucho:

```sql
CREATE TABLE prueba AS SELECT 1 AS id, 'POINT(0 0)'::GEOMETRY AS g;
```
