# Atajos del teclado

## En todo GeoDuck

| Atajo | Qué hace |
|---|---|
| F1 | Abre esta guía en la página de lo que estás viendo |
| Ctrl+K | Buscar tablas, consultas y acciones |
| Ctrl+B | Mostrar u ocultar el explorador |
| Ctrl+W | Cerrar la pestaña |

## Ejecutar

| Atajo | Qué hace |
|---|---|
| Ctrl+Intro | Ejecutar todo, o la selección |
| Ctrl+Shift+Intro | Ejecutar la sentencia marcada |
| Esc | Cancelar mientras corre |
| Ctrl+J | Plegar o abrir el resultado |

## Editor

| Atajo | Qué hace |
|---|---|
| Ctrl+Espacio | Autocompletar |
| Ctrl+Shift+Espacio | Parámetros de la función |
| Ctrl+F / Ctrl+H | Buscar / reemplazar |
| Ctrl+G | Ir a la línea |
| Ctrl+/ | Comentar o descomentar |
| Alt+↑ / Alt+↓ | Mover líneas |
| Shift+Alt+↓ / Shift+Alt+↑ | Duplicar líneas |
| Ctrl+Shift+K | Borrar líneas |
| Ctrl+D | Elegir la palabra y su siguiente aparición |
| Alt+clic | Añadir un cursor |
| Shift+Alt+F | Formatear el SQL |
| Ctrl+Shift+U | Mayúsculas ↔ minúsculas |
| Alt+Z | Ajustar líneas largas |
| Ctrl++ / Ctrl+- / Ctrl+0 | Zoom |
| Ctrl+S / Ctrl+O | Guardar / abrir consulta |

## Tablas y resultados

| Atajo | Qué hace |
|---|---|
| Ctrl+C | Copiar lo elegido |
| Ctrl+A | Elegir todo |
| Ctrl+Inicio / Ctrl+Fin | Primera / última fila |
