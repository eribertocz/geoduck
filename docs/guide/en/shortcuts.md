# Keyboard shortcuts

## Everywhere in GeoDuck

| Shortcut | What it does |
|---|---|
| F1 | Opens this guide on the page of what you are looking at |
| Ctrl+K | Search tables, queries and actions |
| Ctrl+B | Show or hide the explorer |
| Ctrl+W | Close the tab |

## Run

| Shortcut | What it does |
|---|---|
| Ctrl+Enter | Run the selection or the marked statement |
| Ctrl+Shift+Enter | Run everything |
| Esc | Cancel while it runs |
| Ctrl+J | Fold or open the result |

## Editor

| Shortcut | What it does |
|---|---|
| Ctrl+Space | Autocomplete |
| Ctrl+Shift+Space | Function parameters |
| Ctrl+F / Ctrl+H | Find / replace |
| Ctrl+G | Go to line |
| Ctrl+/ | Comment or uncomment |
| Alt+↑ / Alt+↓ | Move lines |
| Shift+Alt+↓ / Shift+Alt+↑ | Duplicate lines |
| Ctrl+Shift+K | Delete lines |
| Ctrl+D | Select the word and its next occurrence |
| Alt+click | Add a cursor |
| Shift+Alt+F | Format the SQL |
| Ctrl+Shift+U | Upper ↔ lower case |
| Alt+Z | Wrap long lines |
| Ctrl++ / Ctrl+- / Ctrl+0 | Zoom |
| Ctrl+S / Ctrl+O | Save / open query |

## Tables and results

| Shortcut | What it does |
|---|---|
| Ctrl+C | Copy the selection |
| Ctrl+A | Select all |
| Ctrl+Home / Ctrl+End | First / last row |
